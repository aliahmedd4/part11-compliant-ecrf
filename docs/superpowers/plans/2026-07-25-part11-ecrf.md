# Part 11 Compliant eCRF Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a minimal 21 CFR Part 11 eCRF (MERN) whose every regulatory control is enforced server-side and proven by an executable OQ suite, then wrap it in a full CSV validation package.

**Architecture:** Express API with a single service layer that is the only writer of data (it computes audit diffs, stamps server time, enforces soft-delete and signature locks). RBAC via a central permission matrix + middleware. Mongoose plugins make `AuditEvent` append-only and strip hard-deletes globally. React/Vite client reflects — never enforces — permissions. `mongodb-memory-server` provides the DB for dev/test/CI.

**Tech Stack:** Node 24, Express, Mongoose, mongodb-memory-server, bcryptjs, jsonwebtoken, Jest + supertest (API OQ), Playwright (UI OQ), React + Vite, GitHub Actions.

Design spec: `docs/superpowers/specs/2026-07-25-part11-ecrf-design.md`. Read it first.
